# Better Toolbar // Capri

Enhances Capri's floating toolbar (`TalkPill`) with smart positioning, auto-hide controls, a Hologram mode toggle, an animated minimize-to-tray button, and synchronized native glitch effects across all toolbar mods.

## Features

- **Smart Non-Overlap Layout:** Automatically detects Capri's actual sprite bounds and keeps the entire toolbar—including third-party buttons like `Mute Button` and `Better Chat // Capri`—clear of screen edges, the taskbar, and Capri herself (shifting to the left or right when she is near the bottom of the screen).
- **Auto-Hide & Instant Dismiss:** Hides automatically after **2s** (normal) or **2.5s** (Hologram mode) once the cursor leaves the toolbar, and dismisses immediately when clicking outside.
- **Hologram Eye Button:** Adds a native-styled eye toggle on the right side of the toolbar to switch Hologram mode on/off in one click, while keeping `TYPE`, `TALK`, and `MIC` interactive in Hologram mode.
- **Animated Minimize-to-Tray:** Compact tray button that smoothly slides and collapses all toolbar buttons (including mod buttons) into a discreet handle, remembering your preference between sessions.
- **TYPE Toggle:** Clicking `TYPE` opens the input box, and clicking it a second time closes it.
- **Native Glitch Sync:** Mirrors Capri's native 4-frame glitch-in animation on the Hologram button, tray button, and any active toolbar mod buttons.

## Compatibility

- Requires Capri Desktop **API 3**.
- Fully compatible with **Mute Button** and **Better Chat // Capri** (automatically detects whether they are installed and running).

## Installation

1. Download `better-toolbar-capri.capri-code`.
2. Import it in Capri Desktop via **Mods**.
