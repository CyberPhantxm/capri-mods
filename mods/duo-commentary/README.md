# Duo Commentary

Switch between roast and serious style and get random canned one-liners from Capri on request. It does not look at your screen.

- Kind: code mod
- Made by: flaqueeee

## Commands

- "commentary on" / "commentary off" - turn commentary on or off (counts the lines you asked for)
- "roast mode" - sarcastic lines
- "serious mode" - calm, professional lines
- "commentary quip" - one random line in the current style
- "commentary help" - list the commands

The lines come from a fixed list in the mod, picked at random. Nothing is saved to disk.

Code mods are Windows only for now.
