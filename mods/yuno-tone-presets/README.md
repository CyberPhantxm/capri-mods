# Tone Presets

Choose a calm, playful or direct tone for Capri's chat replies from her Mods menu.

- Kind: code
- Made by: YunoTheAlien

Import `yuno-tone-presets.capri-code` from **Mainframe > CAPRI > Mods > Import mod** and approve the personality permission. Right-click Capri and open **Mods** to select **Tone: Calm**, **Tone: Playful** or **Tone: Direct**. The mod remembers your selection across restarts. Choose **Tone: Default** to clear it.

Each preset adds one style note to Capri's chat prompt. The selection is stored locally, and Capri includes the style note in requests to your configured chat brain. The mod starts with Capri's default tone on first use.

The tone-preset idea comes from YunoTheAlien's Dynamic feature. [Source at bc0a118e](https://github.com/YunoTheAlien/capri-abliterated-desktop/blob/bc0a118ea5d9e27a9a17ef2b8fc8c4a5b0563389/app/Dynamics.cs)
