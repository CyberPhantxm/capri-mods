# Gaming Coach

Times your gaming sessions, records wins and losses, and tracks streaks, win rate and tilt. It only works from what you tell it.

- Kind: code mod
- Made by: flaqueeee

## Commands

- `start game timer` starts a timer for your game.
- `game over` (or `end game timer`) stops it and asks if it was a W or an L. Answer within about 2 minutes with `w`, `l`, `win`, `loss`, `won`, `lost`, `i won` or `i lost`. Any other line cancels the question.
- `game won` / `game lost` records a result while a timer is running.
- `coach tilt check` checks your last games for tilt.
- `game stats` shows games, win rate and hours played.
- `game streak` shows your current streak.
- `game help` lists the commands.

Results are saved in `game-sessions.txt` in this mod's own folder. Code mods are Windows only for now.
